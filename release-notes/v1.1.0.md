LayerHound 1.1 finds your printers for you, runs on more machines, and comes as a Docker image.

## New

**Printer suggestions**
- LayerHound now looks for printers on your network by itself: right after first-run setup, then once a day.
- Printers it finds appear on the Dashboard and Print Farm pages:
  - **Klipper:** one click to add.
  - **Bambu Lab:** enter the printer's access code. LayerHound hears Bambu printers announce themselves, so their name, model and serial are filled in.
  - **OctoPrint:** click "Allow" in OctoPrint. No API key to copy.
- Not yours? Hide it and it won't be suggested again.
- Settings → Printer discovery turns the daily scan off, or adds Klipper printers without asking (off by default, for shared networks).

**Docker**
- Run LayerHound on any Linux machine, a NAS (Unraid, Synology, TrueNAS) or Docker Desktop with one command: `docker compose up -d`.
- The image is `ghcr.io/teamtacticalrc/layerhound`, for Intel/AMD and ARM.
- Your data lives in its own volume and survives updates. To update, run `docker compose pull && docker compose up -d`.

**Any Debian-based PC**
- The installer now works well on ordinary PCs and mini PCs, not just boards.
- If port 80 is taken, choose another with `--port 8080`. The installer stops with a clear message instead of failing.
- The setup hotspot is now for boards only: Settings → Setup hotspot (Auto, On or Off). A Linux laptop that loses its network won't turn its Wi-Fi into a hotspot.

## Improved

- **Security:** connections to printers, cameras and other apps require TLS 1.2 or newer, and error messages no longer show technical details. LayerHound's code is now public, with automatic code scanning, dependency alerts and secret scanning.
- **The LayerHound board case, version 2:** the fan moved 6.5 mm and the case is 4 mm deeper, so the fan can be held with M3 × 16 bolts and nuts without hitting the board. The print files and guide are in the source repository under hardware/case.

## Updating

- **LayerHound board or Linux install:** Settings → Updates → Update now. Your printers and settings are kept, and the previous version comes back by itself if anything goes wrong.
- **Docker:** this is the first Docker release. See the owner's guide to get started.

Owner's guide: https://github.com/TeamTacticalRC/LayerHound/blob/main/docs/GUIDE.md
