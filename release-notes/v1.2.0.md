LayerHound 1.2 can update itself overnight, and asks whether you'd like to share anonymous usage stats.

## New

**Automatic updates (optional)**
- Settings → Updates → **Install updates automatically**, then pick a time, for example 3:00 AM. It's off unless you turn it on.
- The time is in your own time zone. Once a day at that time, LayerHound installs a new version by itself, the same way as Update now: the database is backed up first, and if the new version doesn't start, the previous one comes back.
- A version that didn't work isn't tried again automatically, and an update that needs a full install waits for you.
- Settings → Updates shows when LayerHound last updated itself.

**Anonymous usage stats (optional)**
- LayerHound asks once whether you'd like to help Team Tactical RC see how many farms use it. Nothing is sent unless you say yes, and you can change your answer in Settings → Usage stats.
- If you say yes, once a day it sends: a random ID made up on your board, the LayerHound version, how it's installed, the board model, how many printers of each type you have, and your country. No names, addresses, serial numbers, access codes or print history.
- Settings shows exactly what's sent.

## Improved

- **Settings is easier to find your way around:** the sections you use most (farm and display, appearance, alerts, updates, accounts) are at the top, and set-once ones further down.
- **The LayerHound board case, version 3:**
  - The base now covers the whole bottom and braces the thin wall between the USB and Ethernet ports.
  - It has pockets for 3M Bumpon SJ5302 stick-on feet.
  - The screws go into the lid more easily.
  - The print files and guide are in the source repository under hardware/case.

## Updating

- **LayerHound board or Linux install:** Settings → Updates → Update now. Your printers and settings are kept, and the previous version comes back by itself if anything goes wrong. After this update, you can turn on automatic updates in the same place.
- **Docker:** `docker compose pull && docker compose up -d`.
