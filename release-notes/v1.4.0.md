LayerHound 1.4 tidies up Settings and gives LayerHound its own, locked-down place on your board.

## New

**Settings in tabs**
- Settings is no longer one long page: **General**, **Printers**, **Accounts**, **Network** and **System** tabs across the top, with the things you use most at the top of each.
- LayerHound remembers the last tab you used on each device, and hints elsewhere in the dashboard (like "turn on Settings → Printer controls") now take you straight to the right tab.

## Improved

**More secure: LayerHound runs on its own**
- LayerHound now runs as its own account, with no password, no login and no admin rights, instead of as your login account. Its code lives in `/opt/layerhound`, where it can't change it, and its data in `/var/lib/layerhound`.
- If anyone ever broke into LayerHound, they'd be shut in there: away from your account, your files and `sudo`.
- Updates are checked twice: once when downloaded, and again by the part that installs them, which only installs packages signed by Team Tactical RC.
- Nothing changes in how you use it: same address, same sign-in, same printers and settings.
- One thing to know if you reach the board's files directly (over SSH or a network share): the **LayerHound Files** folder moves from `~/LayerHound Files` to `/var/lib/layerhound/files`. The Storage page works as before.

## Updating

This update moves LayerHound to its new place, so it installs from the board itself instead of with one click:

1. On the LayerHound board (over SSH, or with a keyboard and screen), run the command shown in **Settings → Updates** (it has a Copy button):
   `curl -fsSL https://github.com/TeamTacticalRC/layerhound-releases/releases/latest/download/install.sh | bash -s -- --update`
2. Type your password when asked. It takes a few minutes.

Your printers, settings, accounts, print history and files are copied over and kept, and the database is backed up first. The old `~/layerhound` folder is left exactly as it was, as a fallback; once you're happy, you can delete it. If you ever need to go back, `bash /opt/layerhound/deploy/revert-to-home-install.sh` returns to 1.3.0 with your current data.

Forgot your password later? `layerhound reset-password` still works; it now asks for the board's password first.

**Docker:** `docker compose pull && docker compose up -d` (nothing moves in Docker).
